CLOUD BUILD WORKFLOW

Prepare an Android APK build

Generate a GitHub Actions workflow file for a Unity project. You must commit a complete Unity project and configure the required Unity licence credentials in GitHub repository secrets.

Important: This generates a workflow file; it does not build the APK on your phone. Unity licence setup and current GameCI compatibility must be checked before running it.

GitHub repository checklist

  1. Repository includes Assets/, Packages/ and ProjectSettings/.
  2. Workflow is saved under .github/workflows/build-android.yml.
  3. Configure Unity licence secrets as required by the build action.
  4. Run the workflow from GitHub Actions and download the APK artifact if successful.
QUICK START

Use it from Android

  1. Start here

    Use the Files tab to edit or add scripts. Select a file in the project explorer.

  2. Export your project

    Choose Export Unity project ZIP. The ZIP preserves paths so files can be copied into a Unity project.

  3. Use a real Unity project

    These starter files are not a complete Unity project. Create or open a Unity project in Unity Editor on a supported computer or cloud workspace.

  4. Build the APK

    Commit the full project to GitHub, generate the workflow in the Android build tab, configure licence secrets and run Actions.

  5. Install the app

    Host this workspace on HTTPS to install it as a PWA. Open it in Chrome and choose Install app or Add to Home screen.
